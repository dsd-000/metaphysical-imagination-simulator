## How to Add a File to This Repo

### Using the GitHub Website (easiest)

1. Go to the repository page on GitHub.
2. Click **Add file** → **Upload files**.
3. Drag and drop your file(s) or click **choose your files** to browse.
4. Scroll down, add a short commit message (e.g. `Add my new file`), and click **Commit changes**.

### Using Git on Your Computer

1. **Clone** the repository (one-time setup):
   ```bash
   git clone https://github.com/dsd-000/metaphysical-imagination-simulator.git
   cd metaphysical-imagination-simulator
   ```

2. **Copy** your new file into the cloned folder.

3. **Stage** the file:
   ```bash
   git add your-file-name
   ```

4. **Commit** the change:
   ```bash
   git commit -m "Add your-file-name"
   ```

5. **Push** to GitHub:
   ```bash
   git push
   ```

Your file will now appear in the repository on GitHub.
